# 애드노트 ADNOTE

네이버 검색광고 CSV 성과 보고서. 정적 사이트로 배포되며 CSV와 운영 기록은 각 이용자의 브라우저에서 처리·저장됩니다.

## 사용법
1. CSV 양식을 내려받아 날짜, 캠페인 유형, 광고비, 구매매출, 구매완료, 클릭수, 노출수를 입력합니다.
2. CSV 업로드 시 일자, 캠페인, 광고비, 구매매출, 구매완료수, 클릭수, 노출수 열을 한글·영문 표기와 괄호/공백 차이까지 고려해 자동으로 연결합니다. 연결이 모호한 열만 직접 선택하면 됩니다.
3. 연결된 데이터는 기존 데이터에 누적 저장됩니다. 새 날짜는 추가되고, 이미 저장된 날짜가 CSV에 포함되면 그 날짜의 기존 데이터를 새 파일 내용으로 전부 갱신합니다. 한 파일 안의 동일 일자·캠페인 행은 합산되며 원본 합계 행은 제외하세요.
4. 설정에서 보고서 이름과 목표 ROAS를 변경합니다.
5. 운영 기록을 추가하면 해당 날짜의 주간 상세에 운영 내용과 다음 확인 항목이 표시됩니다.
6. 주차를 클릭해 펼치거나 접습니다. 최근 10주를 표시하며 월요일~일요일 기준입니다.
7. PDF / 인쇄에서 PDF로 저장합니다. 보고서 백업 JSON은 다른 기기에서 불러올 수 있습니다.

선택 기간 성과 카드는 노출수, 클릭수, 클릭률, 광고비, 구매완료수, ROAS 순서로 표시합니다. 주간 상세에서는 광고비, 구매완료수, 매출액, ROAS의 바로 전 주 대비 증감률을 함께 보여줍니다.

## 계산
ROAS = 구매매출 합계 / 광고비 합계 × 100. 클릭률 = 클릭수 합계 / 노출수 합계 × 100. 분모가 0이면 표시하지 않습니다. 비교는 바로 전 동일 일수 기간 기준입니다. 예시 데이터는 합성 데이터입니다.

## 제약
네이버 API 자동 연동, 회원 계정, 서버 동기화는 제공하지 않습니다. CSV 재업로드는 기존의 다른 기간과 운영 기록을 유지합니다. 같은 일자·캠페인은 중복 집계를 막기 위해 최신 파일 값으로 갱신됩니다. 브라우저 저장공간이 부족하면 백업 파일로 보관하세요. 기록의 클라우드 공유는 없으며 공개 URL은 도구 자체에 대한 접근을 제공합니다.

## 확인
CSV 2행(광고비 55,000원, 매출 280,000원, 구매 10건)의 합산 ROAS 509.09%, 클릭률 1.29% 확인. 운영 기록 저장·새로고침 유지·주간 상세 연결·접기/펼치기 확인. 390px 모바일 너비의 가로 넘침 없음 확인. WebMCP 기간 조회 및 잘못된 날짜 거부 확인.
